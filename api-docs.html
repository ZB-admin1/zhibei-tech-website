📚 API 文档

智北科技 AI API · v1.0.0 · 简洁、稳定、高性能的企业级 AI 接口

简介

智北科技 AI API 为开发者提供标准化的 RESTful 接口，让您能够轻松将自研大模型能力集成到自己的应用中。我们的 API 支持对话、文本生成、代码生成、数据分析四大核心能力。

✨ 特点：自研大模型驱动 · 毫秒级响应 · 全语言 SDK · 99.9% SLA · 私有化部署支持

认证

所有 API 请求需在 HTTP Header 中携带 API Key：

HTTP Header
Authorization: Bearer zb-your-api-key-here
Content-Type: application/json
🔑 获取 API Key：访问官网注册后，在控制台"API 密钥"页面生成。每个账号最多可创建 5 个 API Key。

基础 URL

基础地址
生产环境: https://api.zhibeitech.com/v1
本地调试: http://localhost:8080/api
演示环境: http://localhost:8080/api

快速接入

cURL

chat 接口示例
curl -X POST http://localhost:8080/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zb-large-v1",
    "message": "你好，介绍一下自己"
  }'

JavaScript / Node.js

import { ZhiBeiAI } from '@zhibeitech/sdk';

const ai = new ZhiBeiAI({ apiKey: 'zb-your-key' });

async function main() {
  const { reply, usage } = await ai.chat([
    { role: 'user', content: '帮我写一个快速排序' }
  ]);
  console.log(reply);
}
main();

Python

from zhibeiai import ZhiBeiAI

ai = ZhiBeiAI(api_key="zb-your-key")

response = ai.chat(
    model="zb-large-v1",
    message="写一个快速排序函数"
)

print(response.reply)

API 端点

GET
/api/health

服务健康检查，返回 API 运行状态和版本信息。

响应示例

{
  "status": "healthy",
  "service": "ZhiBei AI API",
  "version": "1.0.0",
  "timestamp": "2026-10-31T14:00:00Z"
}
GET
/api/models

获取当前账户可用的 AI 模型列表及详细参数。

响应示例

{
  "models": [
    {
      "id": "zb-large-v1",
      "name": "智北大模型",
      "context_length": 8192,
      "capabilities": ["chat", "generate", "code", "analyze"]
    }
  ]
}
POST
/api/chat

AI 对话接口，支持多轮上下文对话。

请求参数

参数类型必填说明
modelstring否模型 ID，默认 zb-large-v1
messagestring是用户消息内容
messagesarray否多轮消息数组（优先级高于 message）
temperaturefloat否0-1，越高越有创造性，默认 0.7
max_tokensint否最大生成 token 数，默认 2048

请求示例

{
  "model": "zb-large-v1",
  "message": "你好，介绍一下自己",
  "temperature": 0.7
}

响应示例

{
  "id": "chat_883451",
  "model": "zb-large-v1",
  "reply": "您好！我是智北 AI 助手...",
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 128,
    "total_tokens": 140
  },
  "timestamp": "2026-10-31T14:00:00Z"
}
POST
/api/generate

智能文本生成接口，支持文章、摘要、翻译、创意写作等场景。

请求参数

参数类型必填说明
promptstring是生成提示词
modelstring否模型 ID
taskstring否任务类型：generate/summarize/translate
POST
/api/code

AI 代码助手，支持 Python、JavaScript、Go、SQL 等主流语言的代码生成与调试。

请求参数

参数类型必填说明
promptstring是代码需求描述
languagestring否目标语言，默认 python
modelstring否推荐使用 zb-code-v1
POST
/api/analyze

AI 数据分析接口，自动识别趋势、检测异常、生成洞察。

请求参数

参数类型必填说明
data_descriptionstring是数据描述或数据本身
taskstring否任务类型：trend_detection/anomaly_detection/forecast

错误码说明

HTTP 状态码说明
200请求成功
400请求参数错误
401API Key 无效或缺失
403权限不足 / 额度耗尽
404接口不存在
429请求过于频繁，触发限流
500服务器内部错误
